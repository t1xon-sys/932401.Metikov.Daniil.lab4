# Лабораторная работа №4. Основы JavaScript


**Тема:** «Студент-разработчик» (Вариант 1: баллы за лабораторные)
**Автор:** Метиков Даниил


## Задание

Добавить на страницу скрипт `script.js`, который реализует:

- ввод/вывод: `prompt` (имя), `alert` (приветствие), `console.log`;
- условные конструкции и циклы;
- функции для поиска максимума, фильтрации и подсчёта суммы в массиве.
**Данные:** массив из 5–7 чисел, баллы за лабораторные работы (от 0 до 100).


**Логика:**
- функция фильтрации оставляет только баллы ≥ 80 («отлично»);
- цикл проходит по исходному массиву и считает работы с баллом < 50 (неудовлетворительно);
- функции `findMax`, `filterHighScores`, `calculateSum`.

**Вывод:**
- `alert`: приветствие с именем студента и сообщение «У вас X отличных работ, максимальный балл – Y»;
- `console.log`: средний балл и количество неудовлетворительных работ;
- дополнительно: в консоль выводится мотивационное сообщение.


Скрипт подключается в `index.html` перед закрывающим тегом `</body>`
